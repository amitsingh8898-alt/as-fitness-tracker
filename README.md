# AS Fitness Tracker — MVP prototype

This is the first working, mobile-first prototype for Amit Singh Fitness.

## Included
- Trainer/client role selection
- Client list
- Exercise library
- Workout logging
- Sets, weight and reps
- Average heart rate, RPE and duration
- Long-term workout history
- Basic strength progress chart
- PWA manifest
- Browser localStorage for prototype data

## Important
This version is a prototype. Client data is stored in the browser and is NOT suitable for real client records yet.

Next production step: connect Supabase Auth + PostgreSQL + Row Level Security so each trainer/client has a secure account and permanent cloud history.

## Deploy
Upload the files to a GitHub repository and import the repository into Vercel. No custom domain is required.
